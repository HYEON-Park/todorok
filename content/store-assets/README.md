# 투두록 — Google Play 이미지 자료

플레이 콘솔 "스토어 등록정보 > 그래픽" 에 아래 파일을 업로드하세요.

| 파일 | 용도 | 규격 | 상태 |
|------|------|------|------|
| `icon-512.png` | 앱 아이콘 | 512×512 PNG | ✅ 규격 충족 |
| `feature-1024x500.png` | 피처 그래픽 | 1024×500 PNG | ✅ 규격 충족 |
| `screenshot-1-calendar.png` | 스크린샷 ① 달력 | 1200×2340 (비율 1.95:1) | ✅ 2:1 이내 |
| `screenshot-2-diary.png` | 스크린샷 ② 일기 목록 | 1200×2340 | ✅ |
| `screenshot-3-dday.png` | 스크린샷 ③ D-day | 1200×2340 | ✅ |
| `screenshot-4-settings.png` | 스크린샷 ④ 설정 | 1200×2340 | ✅ |

## 참고
- 스크린샷은 실제 앱 화면을 예시 데이터로 채워 캡처한 것입니다.
- 휴대폰 스크린샷은 최소 2장 필요하며, 위 4장을 모두 올리는 것을 권장합니다.
- Google Play 규정: 각 변 320~3840px, 최대 비율 2:1. 위 이미지는 모두 충족합니다.

## ⚠️ 앱(런처) 아이콘 관련
현재 **앱 설치 후 홈 화면에 표시되는 아이콘은 안드로이드 기본 아이콘**입니다.
위 `icon-512.png`(스토어용)과 다릅니다. 통일하려면 이 아이콘을 런처 아이콘으로도
적용하고 AAB를 다시 빌드해야 합니다. (별도 작업 필요)
